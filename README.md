# hueni (Zalo Mini App)

Booking management for Huế homestay owners and their staff, on Zalo. Phone front-end of [hueni-api](https://github.com/trungle1612/hueni-api).

```bash
npm install
npm run dev    # http://127.0.0.1:3000, mock data when VITE_API_URL is empty
npm run build  # → www/
npm run lint
```

Product and glossary: `PRODUCT.md`. Developer notes: `CLAUDE.md`. Screen specs: the [wiki](https://github.com/trungle1612/hueni-zalo/wiki).
